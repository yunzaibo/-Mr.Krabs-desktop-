## What Changed

### Result Hero Enhancement (VHC-01)

Result section 从普通 ContextCard 升级为视觉 hero 区域:
- padding: 12px → 16px
- 新增背景色 (`hc-surface-elevated`)
- 左侧 3px accent border
- font-size: 13px → 14px, line-height: 1.6 → 1.7
- max-height: 400px → 500px

**效果**: Result 区域在视觉上与其他 section 产生明确层次区分，用户一眼能看到"这是最重要的内容"。

### Action Bar Hierarchy (VHC-02)

三个按钮从统一 outline 样式升级为三级视觉层级:
- Modify Instruction: **filled primary** (实心背景 + 白色文字)
- Copy Result: **outlined secondary** (边框 + accent 色)
- Back to Chat: **ghost tertiary** (无边框 + muted 色)

**效果**: 用户能直观感知"修改指令"是最核心操作，"返回对话"是低优先级。

### Terminology Refinement (VHC-07 partial)

4 个 DevOps 术语替换为用户语言:
| 之前 | 之后 |
|------|------|
| 执行 (Execution) | 进度 (Progress) |
| 健康 (Health) | 状态 (Status) |
| 无异常 (No issues) | 一切正常 (All good) |
| 严重 (Critical) | 出错了 (Something went wrong) |

## Remaining Runtime Residues

以下内容仍暴露 Runtime 内部状态，尚未处理:

| 残留 | 位置 | 影响 |
|------|------|------|
| taskId 显示 | Task section | 用户不需要知道内部 ID |
| inputSummary / outputSummary | Task section | JSON 截断对用户无意义 |
| skillName / skillId + version | Skill section | 开发者信息 |
| state + stage + stepCount | Execution section | Runtime ontology |
| mimeType / dimensions / sizeBytes | Result items | 元数据噪音 |
| Health toggle + severity | Health section | 已改文案但仍独立卡片 |

这些是 **information architecture** 层面的问题，需要 PLN-020 (非 020A) 处理。

## Why Workspace Is Still Not Fully AI-native Runtime

### 1. 它是"可观测面板"，不是"任务工作台"

Workspace 的设计起点是 **observability**（可观测性），而非 **operability**（可操作性）。5 个 section 平铺展示 Runtime 内部状态，像 Grafana dashboard 而非 IDE。

**AI-native Runtime 应该是**: 用户说"帮我总结这篇文章"，Workspace 展示"正在处理 → 这是结果 → 你可以修改指令重试"。而不是展示 skillId、stepCount、mimeType。

### 2. 信息层级未建立

所有 ContextCard 使用相同的 1px border + 12px padding，没有视觉优先级。Result hero 改善了这一点，但 Skill/Execution/Health 仍在同一视觉层级。

### 3. 缺少"下一步"引导

Action Bar 提供了操作按钮，但没有上下文感知。completed 任务和 running 任务显示相同的 Action Bar，没有根据状态引导用户。

### 4. 没有任务状态感知的布局

Running 和 completed 任务使用相同的 5 section 布局。AI-native Runtime 应该:
- Running: 突出 Execution/Progress，弱化 Result
- Completed: 突出 Result，弱化 Execution
- Failed: 突出 Error + Health，提供 Retry 入口
